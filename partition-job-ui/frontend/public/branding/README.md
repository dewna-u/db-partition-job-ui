# Branding assets

Place the official PartOps logo here:

- `partops-logo.png` — optional full logo (transparent background preferred)
- `partops-mark.svg` — compact sidebar/favicon mark (shipped)

The UI uses the SVG mark by default for sidebar/favicon readability in light and dark themes.
Drop `partops-logo.png` when available; pages that show a larger brand block will prefer it when present.
