# Streamlit UI archive

The previous Streamlit presentation layer was archived here so it is not deleted permanently.

Active UI is now:

- `frontend/` — Next.js
- `api/` — FastAPI

Archived files typically include:

- `app.py`
- `ui_overview.py`
- `ui_theme.py`
- `.streamlit/`

To restore temporarily for comparison:

```bash
unzip streamlit-ui-YYYYMMDD-HHMMSS.zip -d ../streamlit-restore/
```

Do not unzip back over the live tree unless you intentionally want Streamlit again.
